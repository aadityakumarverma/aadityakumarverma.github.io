# Aaditya Verma — GitHub Pages Portfolio

A responsive, animated dark portfolio made with plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Create a public repository named `aadityakumarverma.github.io`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Your site will be published at `https://aadityakumarverma.github.io`.

The résumé PDF is included in `assets/` and linked from the hero and contact sections.

## Before publishing
- Check résumé details and links.
- The Mirai and VedRashi project links currently point to your GitHub profile because direct repository URLs were not supplied.
- Add a project repository URL when you want those cards to link to their source repositories.
